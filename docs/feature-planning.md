# Web Clipboard 进阶规划方案

> 本文档针对项目后续的**用户权限体系、组织群组分类、定向协作共享、2FA 双因子安全认证以及异地防凭证泄漏**进行系统化架构设计与落地规划。

---

## 一、背景与设计原则

当前系统已完成了全屏工作台改造、无闪烁首屏直出（Anti-FOUC）、顶栏嵌入式搜索、纯剪贴板单行输入坞、卡片尺寸自由微型滑块（方案 A）以及智能时间轴分组。

针对下一步演进，确立以下四个核心原则：
1. **闭门受控，禁止自由注册**：系统定位为高私密性的个人与受信任群组协作剪贴板，严禁向互联网开放公共注册，所有账号均由管理员统一录入与分配。
2. **纯粹剪切板协作**：专注即时文本、代码片段、截图的高速同步与共享，坚决避免引入厚重的网盘附件与大文件存储。
3. **主私有流与共享收件箱隔离**：外部定向分享的内容必须进入独立的“共享收件箱”，不得污染用户的个人时间流，支持自主“转存到我的消息”或“仅复制”。
4. **异地零信任与防凭证泄漏（Zero Trust for Remote Logins）**：通过 2FA（基于 TOTP 的 6 位动态验证码）与沙盒会话机制，即便在不可信电脑被键盘记录器（Keylogger）截获密码，攻击者也绝对无法再次登录。

## 三、详细方案设计

### 1. 管理员专控用户与分类体系 (Admin-only RBAC)

#### 数据持久化模型
弃用环境变量中的静态逗号分隔配置，改由持久化挂载的数据文件 `data/users.json` 与 `data/groups.json` 管理（容器重建不丢失）：

- **用户定义 (`data/users.json`)**：
  ```json
  [
    {
      "id": "u_admin",
      "username": "admin",
      "name": "超级管理员",
      "role": "admin",
      "groupIds": ["admin_group"],
      "passwordHash": "$2b$10$...",
      "totpSecret": "JBSWY3DPEHPK3PXP",
      "totpEnabled": true,
      "createdAt": 1728900000,
      "status": "active"
    },
    {
      "id": "u_dev01",
      "username": "zhangsan",
      "name": "张三",
      "role": "member",
      "groupIds": ["dev_team"],
      "passwordHash": "$2b$10$...",
      "totpSecret": "",
      "totpEnabled": false,
      "createdAt": 1728905000,
      "status": "active"
    }
  ]
  ```

- **分类群组定义 (`data/groups.json`)**：
  ```json
  [
    {
      "id": "dev_team",
      "name": "研发团队",
      "description": "包含前后端开发与核心测试人员",
      "createdAt": 1728900000
    },
    {
      "id": "ops_team",
      "name": "系统运维",
      "description": "生产服务器与基础服务维护",
      "createdAt": 1728900000
    }
  ]
  ```

#### 管理接口与安全守卫
- `GET /api/admin/users`：获取系统用户清单与所属群组；
- `POST /api/admin/users`：录入新账号（由管理员分配初始密码与角色）；
- `PATCH /api/admin/users/:id`：修改成员所属群组、停用账号或重置密码；
- `DELETE /api/admin/users/:id`：物理移除用户及其私有数据；
- `GET /api/admin/groups` & `POST /api/admin/groups`：维护群组与分类；
- **守卫机制**：仅携带 `role: 'admin'` 的会话允许请求上述路径，普通成员访问固定返回 403 Forbidden。

### 2. 定向共享与隔离收件箱 (Targeted Sharing & Inbox)

#### 接收端交互形态：顶栏「共享」Tab
顶栏的视图切换采用三个标准的双字平级胶囊：
`[ 消息 ]` $\rightarrow$ `[ 收藏 ]` $\rightarrow$ `[ 共享 (未读数) ]`

- **收件流独立**：别人发送的内容，绝不直接插入到自己的个人“消息”流中，避免主私有时间线混乱。
- **卡片展示强化**：
  - 顶部显式展示协同来源标签：`👤 @张三 分享给我 · 10:25` 或 `👥 研发团队 群发 · 昨天 16:30`；
  - 提供两个专属动作：
    1. **`📋 复制`**：快速复制到剪贴板，不改变现有数据；
    2. **`📥 转存到我的剪贴板`**：一键将该条内容克隆到自己的“消息”主时间线中，归纳为自己的记录。

#### 发送端操作
- 卡片底部增加极简小巧的 **`↗ 分享`** 按钮；
- 点击后弹出轻量弹窗：列出当前系统所有可选的“个人用户”与“分类群组”；
- 勾选后提交，后端通过 Socket.IO 发送定向事件 `share-new` 到目标用户的个人房间，接收者顶栏的 `[ 共享 ]` 即刻弹出红点并播放轻提示。

### 3. 2FA 双因子认证与异地防泄漏安全防护

为了防范异地不可信设备（网吧、外接演示机、会议室公共电脑）被植入键盘记录器（Keylogger）窃取密码，引入 **TOTP 6 位动态验证码二次核验** 与 **沙盒临时会话**。

#### A. 离线 TOTP 6 位动态口令（RFC 6238 标准）
- **零外部通信依赖**：无需绑定手机短信或发送验证邮件，不消耗资费；
- **设备支持**：兼容 Google Authenticator、Microsoft Authenticator、Apple 密码钥匙串，以及 **Apple Watch / 智能手表**（抬手看码即可输入，手机无需拿出）；
- **双重校验流程**：
  ```text
  输入主密码 ──[成功]──► 检测是否开启 2FA ──► [是] ──► 弹出 6 位动态码输入框
                                                          │
                                                输入 30 秒有效动态码
                                                          │
                                                [通过] ──► 下发会话凭据
  ```
- **安全保障**：键盘记录器或截屏即使记录下当前 6 位数，由于该码 **30 秒后全局失效且一次性自毁**，黑客拿着窃取到的主密码和这串数字也无法重新登录。

#### B. 异地沙盒临时会话（Ephemeral Sandbox Mode）
在登录界面提供勾选框：**`[ ] 在公共/临时设备上登录`**
- **零持久化存储**：禁止向浏览器的 `localStorage` 或长期 Cookie 写入任何凭据，只保留在内存与 `sessionStorage`；
- **关标签即自毁**：用户使用完毕只要关闭浏览器标签页，登录态与本地解密数据立刻彻底灰飞烟灭；
- **敏感操作降权**：在临时沙盒会话下，默认禁用重置密码、修改账号安全配置等高危操作。

## 四、分阶段落地实施排期

| 阶段 | 实施内容 | 交付成果与验收标准 |
| :--- | :--- | :--- |
| **阶段 1（已完成）** | 前端全屏工作台改造、去附件化单行输入坞、顶栏卡片缩放微型滑块、时间轴日期分组、Anti-FOUC 首屏无闪秒开。 | 页面刷新 0ms 纯净秒开，布局紧凑无多余空白，Docker 镜像 `1.6.9-p7` 稳定运行。 |
| **阶段 2** | 后端引入 `data/users.json` 与 `data/groups.json`，实现管理员受控账号与群组增删改查及初始化。 | 提供完整的后台管理接口；首个超级管理员以当前环境密码自动初始化。 |
| **阶段 3** | 前端顶栏新增管理员控制台入口，打通【共享】Tab的定向推送通道与“转存到我的剪贴板”交互。 | 成员之间可勾选人或群组进行实时剪贴分享；接收方通过【共享】收件箱接收并转存。 |
| **阶段 4** | 引入 TOTP 2FA 双因子校验库与沙盒临时会话模式，配套应急自毁码。 | 异地设备登录必须通过 6 位动态口令二次核验；勾选临时设备关浏览器即彻底登出。 |
