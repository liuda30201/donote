# 上游参考资料

应用来源：[aiChenK/web-clipboard](https://github.com/aiChenK/web-clipboard)，上游版本 v1.6.8。MIT 许可证保留在项目根目录 `LICENSE`。

本目录保存导入时的中文/英文 README、更新日志和 Docker 发布工作流，供了解上游功能与历史使用。`docker-publish.yml` 在此处不会被 GitHub Actions 执行。

这些资料描述上游默认行为，包含免密码部署、公开分享等内容。本地部署使用登录保护、禁用公开分享及直接访问上传目录，加入卡片布局、历史搜索、文件预览、凭据解析、持久化与清理补丁。实际部署以根目录 README、`docs/operations.md`、Compose 和当前代码为准。

上游更新时对照本地改动合并，保留版权信息；不要将本目录的发布配置直接作为当前仓库的发布流程。
